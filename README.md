# 🐍 Python + DSA + AI/ML — Learning Workspace

A complete, hands-on roadmap from Python basics to AI/ML, organized into **10 phases** and **114 topics**. Every topic folder contains three files designed to be worked in order.

## How to use this repo

For **each topic**, follow this 3-step learning loop:

1. **`README.md`** — Read first. Plain-English explanation of *what* the topic is, *why* it matters, the key ideas, a commented runnable example, and common gotchas.
2. **`notes.py`** — Run and tinker. Multiple commented, runnable examples. Execute with `python notes.py`, then change things and re-run to build intuition.
3. **`practice.md`** — Test yourself. 8–10 exercises (easy → hard). Try each before expanding the collapsible solution.

> **Tip:** Don't just read — *run the code and break it*. The fastest way to learn is to change a line, predict what happens, and check.

### Suggested path

- Finish **Phase 1–2** (Python) before anything else.
- Then **Phase 3 (DSA)** and **Phases 4–6 (Math + Data + ML)** can run in parallel.
- **Phases 7–9** build on ML. **Phase 10** is continuous practice — start it early.

### Requirements

- Python 3.10+ for Phases 1–3 (standard library only).
- Later phases use libraries; install per-topic with the `pip install` line in each README, or all at once:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn requests flask fastapi uvicorn streamlit
```
